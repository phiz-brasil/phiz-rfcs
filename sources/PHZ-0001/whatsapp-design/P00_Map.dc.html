KEY DIFFERENCE FROM WHATSAPP
In WhatsApp, opt-in usually happens outside the app and Meta never sees it (O6). Here the user accepts inside PhizChat, so the platform itself holds the proof of consent.
What PhizChat stores
User ID · merchant_id · status (granted / revoked) · timestamp · entry point (link, QR, search…) · app version and wording shown.
What the merchant receives
A webhook when consent changes (proposal: consent_update with granted / revoked), so its own CRM stays in sync.
