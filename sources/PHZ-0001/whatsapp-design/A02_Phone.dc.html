A WhatsApp account = a phone number. Brazilian format: country code +55, 2-digit area code (11 = São Paulo), 9-digit mobile number starting with 9. Businesses address users by this number (e.g. 5511987654321).
Because anyone with the number could technically message the user, consent rules (flow O) are what protect the inbox.
